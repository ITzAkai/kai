# Stremio Kai for Samsung Tizen (TizenBrew)

A port of [Stremio Kai Timeworn](https://github.com/creachec/Stremio-Kai-Timeworn) (LG webOS 3.x)
to old Samsung TVs running Tizen 3.0 or newer, loaded as a [TizenBrew](https://github.com/reisxd/TizenBrew)
app module. Unofficial; not affiliated with Stremio, Stremio Kai, LG or Samsung. GPL-3.0, like the original.

Install: TizenBrew → Module Manager → Add module → GitHub → `ITzAkai/stremio-kai-tizen`.

Samsung changes: Return/media/colour keys, exit, TV IP lookup for the stremio-service scan,
model info, and no update checks against the LG release feed. Torrents still need
[stremio-service](https://github.com/Stremio/stremio-service/releases) on a PC on the same network;
direct (debrid) links play without it.
